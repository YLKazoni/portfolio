Note technique. Un fichier .pbix est un format binaire propre à Power BI Desktop : les navigateurs ne savent pas l'afficher nativement, donc cliquer sur l'aperçu ouvre ou télécharge le fichier selon la configuration du navigateur du visiteur — c'est la seule façon d'y accéder sans étape manuelle supplémentaire depuis un simple hébergement statique. Pour un rendu 100 % interactif dans la page (zoom, filtres, clics sur les visuels), chaque rapport devrait être publié sur le Power BI Service via « Publier sur le web », puis intégré ici en <iframe>.
